## 2. Artificial Intelligence (AI)

Artificial Intelligence is a broad field that involves developing intelligent systems capable of performing tasks that typically require human intelligence.

These tasks include:

- Perception
- Reasoning
- Learning
- Problem-solving
- Decision-making

AI is an umbrella term that includes machine learning, deep learning, generative AI, and other approaches.

## 3. Generative AI

Generative AI is a branch of AI that focuses on creating new content based on patterns and relationships learned from existing data.

Unlike traditional AI and ML systems that primarily analyse data, classify information, or make predictions, generative AI can generate new outputs.

### 3.1 Applications of Generative AI

| Application | Description | Example |
|---|---|---|
| Text generation | Produces human-like written content | Generating reports and summaries |
| Image generation | Creates images based on prompts | Generating artwork from text |
| Audio generation | Produces synthetic audio and speech | Creating realistic voices |
| Code generation | Generates or completes programming code | Suggesting code from natural-language instructions |

Examples mentioned in the course include Amazon Titan, Anthropic Claude, and Stable Diffusion.

## 4. Relationship Between AI, ML, Deep Learning, and Generative AI

The technologies are related hierarchically:

**Artificial Intelligence → Machine Learning → Deep Learning → Generative AI**

### 4.1 Artificial Intelligence (AI)

AI is the broadest field. It includes techniques for developing systems that perform tasks associated with human intelligence, including learning, reasoning, and decision-making.

### 4.2 Machine Learning (ML)

ML is a type of AI that enables machines to learn from data and improve their performance on specific tasks.

### 4.3 Deep Learning (DL)

Deep learning is a branch of ML that uses artificial neural networks with multiple layers to learn complex patterns from data.

### 4.4 Generative AI

Generative AI focuses on creating new content, such as text, images, audio, and code, using patterns learned from training data.

## 5. Responsible AI Considerations

Generative AI introduces important responsibilities that must be considered during development and deployment.

- **Bias:** Models may produce biased outputs because of patterns or biases in their training data.
- **Privacy:** Sensitive information must be handled and protected appropriately.
- **Responsible use:** AI systems should be deployed safely and used for appropriate purposes.

These considerations are essential for building trustworthy AI applications.

## 6. Key Terms

| Term | Definition |
|---|---|
| Artificial Intelligence | A field concerned with systems that perform tasks requiring human-like intelligence. |
| Machine Learning | A type of AI that learns patterns from data. |
| Deep Learning | ML based on artificial neural networks with multiple layers. |
| Generative AI | AI that generates new content from learned patterns. |
| Training Data | Data used to teach a model patterns or relationships. |
| Responsible AI | Practices for developing and using AI safely and appropriately. |

## 7. Summary

- AI is the broad field of intelligent systems.
- ML enables systems to learn patterns from data.
- Deep learning uses multilayer neural networks.
- Generative AI creates new content based on learned patterns.
- Responsible AI requires attention to bias, privacy, and appropriate use.
- AWS provides services that help developers incorporate AI and ML capabilities into applications.
